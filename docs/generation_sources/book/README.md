# Архив промптов и результатов — видео с книгой

Дата сборки: 2026-10-28.

## Состав

- `source/video_original.mp4` — исходный загруженный ролик (H.264, без прозрачности).
- `results/kniga_transparent.webm` — полноразмерный WebM c прозрачностью (VP9 + Opus).
- `results/kniga_transparent_compact.webm` — оптимизированный WebM c прозрачностью (VP9 + Opus); удобнее для HTML-презентации.
- `prompts/01_actual_dialogue.md` — точные видимые реплики в текущем чате.
- `prompts/02_reconstructed_processing_task.md` — реконструированное техническое задание (НЕ исходный промпт инструмента).
- `prompts/03_related_prompts_other_assets.md` — связанные запросы о других анимациях из бесед проекта; их результаты в ZIP не входят.
- `metadata/manifest.json` — характеристики и SHA-256 файлов, атрибуция моделей.
- `metadata/model_attribution.csv` — отдельная таблица моделей/инструментов и степени достоверности.
- `verification/ffprobe/*.json` — независимые параметры медиапотоков.
- `verification/sha256.txt` — суммы для проверки целостности.
- `verification/alpha_verification.txt` — декодирование прозрачного WebM и анализ альфа-канала.
- `previews/` — кадры и тест отображения на светлом, тёмном и шахматном фоне.
- `preview.html` — локальный HTML-просмотрщик на разных фонах (звук выключен для автозапуска).

## Что известно о моделях

1. **Модель генерации исходного MP4: неизвестна.** Метаданные H.264/AAC не позволяют определить сервис/модель, создавшую видео.
2. **Создание WebM — техническая обработка исходного файла, а не новая генерация моделью ИИ.** Подтверждён видеокодек VP9 и аудиокодек Opus; команды и инструмент выполнения оригинальной конвертации в истории не зафиксированы.
3. **Модель текущего ассистента при сборке архива: GPT-6.** Это не значит, что GPT-6 генерировала исходное видео.
4. Seedance, Gemini, Google Vids фигурируют только в связанных обсуждениях о **других** анимациях. Доказательств их применения к этому ролику нет.

## Проверка

Для просмотра используйте `preview.html` в браузере (при локальном открытии WebM как правило воспроизводится, но могут быть браузерные ограничения). Прозрачность подтверждена декодированием кадра через `libvpx-vp9`: альфа-канал имеет значения от 0 до 255, полностью прозрачных пикселей в тестовом кадре — 647660 из 921600.

**Важно:** в оригинальном видео есть звуковая дорожка AAC, в двух WebM — Opus. Если звук не нужен, при встраивании в презентацию используйте HTML-атрибут `muted`.
