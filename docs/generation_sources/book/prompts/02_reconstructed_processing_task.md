# Техническое задание, восстановленное из диалога (НЕ оригинальный исполненный промпт)

**Статус:** реконструкция пользовательского задания и описания результата; текст ниже НЕ является журналом вызова модели.

> Взять исходное видео с цветной открытой книгой, бирюзовым световым кольцом и частицами на чёрном фоне. Удалить чёрный фон, сохранив детали книги, свечение, мягкие края и частицы. Не менять геометрию и длительность анимации. Экспортировать WebM с настоящим альфа-каналом для HTML-презентации. Сделать дополнительную компактную версию без потери разрешения 1280 × 720.

**Фактические свойства результата:** VP9, Opus, `alpha_mode=1`, 1280 × 720, около 10 с. Наличие действительного альфа-канала отдельно проверено декодированием с `libvpx-vp9` и анализом PNG.

**Модель:** обработка фона/транскодирование не устанавливает модель генерации исходника. Модель создания исходного ролика **неизвестна**. Точный исполнявшийся скрипт/команда **не сохранились**.
