# AI Flame — архив изображений и промптов

Собрано 28 октября 2026 по доступной истории текущей переписки.

## Содержимое

- `01_references/`: **4** исходных изображения/референса.
- `02_generated_images/`: **6** изображения, полученных в ChatGPT, по порядку итераций.
- `03_video_prompts/`: **20** промптов и коротких добавок к промптам для Gemini/Veo, Seedance, Kling. Есть `ALL_PROMPTS.md`.
- `04_metadata/`: JSON/CSV с разрешениями, хешами, связями, ID генераций, отчётом о тестах и запросами пользователя.
- `05_previews/`: контактный лист с миниатюрами всех изображений.
- `INDEX.html`: локальная галерея для просмотра в браузере.

## Модели: что известно точно

**Изображения:** созданы встроенным инструментом ChatGPT `image_gen`. Вывод инструмента помечен как `DALL-E generation metadata`, но **точная модель/версия не указана**. Не надо автоматически считать её DALL-E 3 либо GPT Image 1.

**Видео:** в переписке были составлены промпты для **Gemini/Veo**, **Seedance**, **Kling AI**. Это целевые сервисы/модели, а не подтверждение использования каждой. По отзыву пользователя, в Gemini был тест с правильным кадрированием, но неудачной желеобразной анимацией. Версия Veo неизвестна. Видео не приложены и не включены.

**Важное ограничение:** реальные внутренние промпты вызовов `image_gen` не были раскрыты инструментом (в метаданных поле `prompt` пустое). Поэтому в `IMAGE_GENERATION_HISTORY.md` сохранены дословные исходные пользовательские запросы, а не вымышленные внутренние промпты.

## Прозрачность

Поле `alpha_channel` в CSV/JSON проверено по фактической PNG-альфе. Не у всех изображений есть прозрачный фон; несмотря на исходное пожелание, некоторые результаты имеют сплошной фон.

## Дубликаты

Исходный файл `generated-image.png` имел тот же SHA-256, что `неоновое_пламя_ai_в_ладони.png`. Копия не дублируется в ZIP.

## Рекомендация для следующих попыток

Начать с короткого `P19` (Gemini) или `P20` (Kling Motion Brush). Для точного loop в HTML можно отделить неподвижный PNG-персонаж и анимировать огонь/частицы отдельным прозрачным слоем.
