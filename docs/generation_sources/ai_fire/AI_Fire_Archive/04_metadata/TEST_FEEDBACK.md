# Отзывы по тестированию видеогенерации (со слов пользователя)

- **Gemini / Veo, версия модели неизвестна:** после длинного промпта с `contain` и safe margins исходная иллюстрация стала полностью помещаться по центру, обрезки не было.
- **Gemini / Veo:** движение выглядело «как желе», а не как пламя. Видео пользователь описал, но **не приложил**.
- Следующие промпты стремились исправить это: движение отдельных языков пламени снизу вверх, отсутствие морфинга шара, добавление анимации частиц и осколков.
- Фактический результат остальных предложенных промптов неизвестен.
- **Никаких видеофайлов в текущем диалоге нет**, поэтому в ZIP они не включены.

Это заметки о ходе работы, а не независимая проверка качества модели.
