# Архив генераций для слайда «От одного сценария к платформе ИИ-агентов»

Дата упаковки: 2026-10-28.

## Содержание
- `references/` — 4 предоставленных изображения/референса.
- `results/` — 9 доступных результатов генерации (изображения PNG).
- `prompts/video/` — 5 основных английских видеопромптов, включая финальный.
- `prompts/user_requests.md` — последовательность пользовательских требований (смысловая запись, не посимвольная стенограмма).
- `manifest.json` и `manifest.csv` — учёт файлов, ID генераций, размеры, прозрачность и данные моделей.

## Модели и достоверность
- Изображения были получены через встроенный инструмент **ChatGPT image generation** (в истории инструмент назван `image_gen.text2im`). Точное наименование/версия базовой модели генерации изображений **не раскрыты**. ID генерации сохранены там, где доступны.
- Точные внутренние текстовые промпты, отправленные генератору изображений, **не сохранены в доступной истории**; не подменяем их выдуманной реконструкцией. В `prompts/user_requests.md` записаны исходные требования пользователя и история итераций.
- Промпты для Google Vids составлены ассистентом в чате. **Ни видео, ни подтверждения о фактическом запуске модели Google Vids/Veo в данном чате нет**; модель видеогенерации поэтому не установлена.
- Название языковой модели, сформировавшей прошлые ответы, отдельно для каждого сообщения не документировано; не приписываем задним числом конкретную версию.
- PNG не всегда содержит прозрачные пиксели, даже если имеет цветовой режим RGBA; см. `has_transparent_pixels` в манифесте.

## Важные ограничения
Это архив доступной истории данного обсуждения, а не экспорт внутренних параметров сервиса. Некоторые системные промпты и результаты генерации видео недоступны. Тексты сценариев для изображений представлены как требования, не как подлинные внутренние промпты.
