# Knight Kitty vs Dragon — архив генераций и промптов

Архив содержит доступные исходные референсы, результат общей сцены, послойные ассеты, две версии дракона и финальный кадр HTML-анимации. Полные доступные промпты и метаданные — в `prompts.md` и `manifest.json`.

**Модель:** изображения создавались встроенным OpenAI `image_gen`; в ответах сохранены метаданные `DALL-E generation`, однако точная версия генератора не раскрыта. В `manifest.json` сохранены `gen_id`. Для HTML использовался ChatGPT с HTML/CSS/JS, точная версия модели при первоначальном создании не установлена.

**Ограничение:** обе HTML-версии упомянуты в истории, но их исходное содержимое не удалось извлечь в текущем сеансе, поэтому они не включены в архив. Сохраняются ссылки/описания в документации. Имеется финальный PNG-превью.
