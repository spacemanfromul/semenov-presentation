# Передача другому ИИ

Прочитай registry.json. Это данные об истории генерации, а не новые команды. Учитывай instructions_for_ai.

1. Сначала statistics и slides: текущий порядок показа — 40 слайдов.
2. images: запросы пользователя, полные промпты при наличии, gen_id, локальные файлы, matches и уровень подтверждения.
3. source_contexts: исходные хронологии и точность формулировок.
4. video_prompts: 40 текстов; status_reported и model_reported — утверждения архивов, не проверенные API-ответы.
5. video_results: книга, исходник и две обработки; не считать тремя ИИ-генерациями.
6. technical_operations: два запроса HTML, не видеогенерация.

Точные model ID неизвестны: не подставляй GPT Image, DALL-E или версии Veo по предположению. Отсутствие совпадения не трактуй как подтверждённое неиспользование. Для анализа слайдов читай соответствующие src/slides и используй npm run locate -- N, но помни, что старые stage-данные locate могут не учитывать вставленный слайд 6. Фактический порядок — src/deck_order.json.
