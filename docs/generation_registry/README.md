# Реестр визуалов презентации

- Для человека: откройте index.html локально в браузере. Интернет не требуется для картинок, реестра и встроенных видео книги. Внешние ссылки на результаты Gemini требуют сети и не проверены.
- Для ИИ: передайте registry.json и, при необходимости, папку media. Поле path_base означает корень репозитория для файлов; presentation_url разрешается относительно docs/generation_registry/index.html. В source_contexts находятся тексты запросов с указанием их точности.
- Все оригиналы и референсы хранятся в media с именами по SHA-256. Повторяющиеся байты не дублируются. Исходные сопроводительные тексты: ../generation_sources. ZIP-файлы и Downloads не нужны для просмотра или повторной генерации реестра.

## Запуск

1. npm run build — собрать один автономный dist/presentation.html. dist игнорируется Git и создаётся на машине получателя.
2. Открыть docs/generation_registry/index.html. Ссылки используют ?slide=N и открывают нужный слайд.
3. npm run registry:build — пересобрать оба реестра после изменения данных. Скрипт использует уже доступный sharp через scripts/regression/runtime.mjs; новые зависимости не устанавливаются. Если sharp отсутствует, нужен доступный Node runtime с этим пакетом через REGRESSION_MODULES. Готовый HTML и JSON не требуют Node или sharp.

## Сопоставление

- exact_sha256: одинаковые байты.
- probable_pixel_similarity: кандидат после нормализации на белом фоне до 96×96; средняя абсолютная ошибка RGB меньше 0.025. Это проверка сходства, а не доказательство происхождения. В HTML рядом показан ассет презентации. Порог фиксирован; обрезанные/скомпонованные изображения могут не найтись.
- context_only: совпадает тема/DOM-назначение, но исходник или вариант файла не установлен. Для книги оба WebM остаются кандидатами.
- not_established: недостаточно доказательств. Не означает, что результат никогда не использовался.

Список ассетов каждого слайда строится по прямым токенам в исходном HTML (включая inline/srcdoc-код). CSS-фоны, растровые картинки внутри SVG и покадровое содержание видео отдельно не распознаются. Общее свечение и шрифты не приписываются конкретной генерации. Сценарий анимации не доказывает, что он исполнялся конкретной моделью.
